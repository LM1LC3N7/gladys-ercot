# Third-party notices

## ERCOT Public API and data

The prices this integration reads come from the public market information of the Electric Reliability
Council of Texas (ERCOT), through the ERCOT Public API (`api.ercot.com`), with the user's own API Explorer
account, under the ERCOT API Terms of Use (<https://www.ercot.com/help/terms/data-portal>). No ERCOT data
is shipped with the image; the test answers are synthetic.

The requests were written from the official documentation (developer.ercot.com, "Registration and
Authentication", "Using the API", "API limitations") and from the OpenAPI description published by ERCOT
in <https://github.com/ercot/api-specs> (`pubapi/pubapi-apim-api.json`, read on 2026-11-14). No code was
copied or ported from them.
